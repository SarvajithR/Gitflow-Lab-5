# Gitflow Lab 5

## Objective
Demonstrate Gitflow using Git, GitHub, VS Code, branches, commits, pushes, merging, and merge-conflict resolution.

## Branch Structure
- main
- develop
- feature/login
- feature/conflict

## Login Feature

The `app.py` program demonstrates a login system with secure authentication.

## Gitflow
1. Create and connect the GitHub repository.
2. Create and push `develop`.
3. Create `feature/login`.
4. Add and commit the login feature.
5. Push `feature/login`.
6. Merge `feature/login` into `develop`.
7. Create `feature/conflict`.
8. Make different README changes on the branches.
9. Merge and resolve the conflict.
10. Commit the resolved file and push `develop`.
